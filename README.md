# Календарь звонков — Step 2


[![hexlet-check](https://github.com/VDA22/ai-for-developers-project-386/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/VDA22/ai-for-developers-project-386/actions)

Разработайте совместно с ИИ сервис для бронирования календаря

Учебный проект Хекслета: https://ru.hexlet.io/programs/ai-for-developers
Как это должно работать: https://files.hexlet.app/a/2ipc5m

## Стек

- Бэкенд: Swift 6.4, Vapor 4.122.4
- Фронтенд: TypeScript, Vite, Mantine

## Установка

```bash
git clone https://github.com/VDA22/ai-for-developers-project-386.git
cd ai-for-developers-project-386
brew install mise
mise install
mise run install
```

## Разработка

Запустите бэкенд:

```bash
swift run --package-path server App
```

В отдельном терминале запустите фронтенд:

```bash
mise run web
```

Фронтенд доступен на http://127.0.0.1:5173, API — на http://127.0.0.1:8080/api/health.

Оба процесса должны быть запущены одновременно: без бэкенда бейдж на главной показывает «Бэкенд недоступен», а `http://127.0.0.1:5173/api/health` отвечает `502`. Проверить готовность можно командой `curl http://127.0.0.1:5173/api/health` — ожидается `{"status":"ok"}`.

## Проверки

Все проверки запускаются одной командой:

```bash
mise run check
```

Она же выполняется в GitHub Actions на каждый push. Быстрая часть доступна отдельно:

```bash
mise run check:fast
```

Git-хуки:

```bash
mise run hooks:install
```

Автоисправление:

```bash
mise run fix
```

## Использование

### Главная и страница записи

1. Откройте http://127.0.0.1:5173 — главная страница рассказывает о сервисе и его возможностях.
2. Нажмите **Записаться** — откроется страница `/booking` с заголовком «Записаться». Пока это заглушка: бронирование появится на следующем этапе.

### Создание типа встречи

1. На главном экране «Админка» нажмите кнопку **+**.
2. Откроется окно «Создание типа встречи»: заголовок, описание, URL и продолжительность.
3. Нажмите **Продолжить** — тип встречи появится в списке на главном экране.

### Запись на свободное время

1. Перейдите по ссылке — откроется окно бронирования: слева данные о встрече (кто назначил, продолжительность, ссылка для подключения, часовой пояс), в центре — календарь на 14 дней, справа — выбор времени.
2. Выберите дату и время: оба параметра обязательны.
3. Откроется окно ввода имени и почты — заполните их и нажмите **Подтвердить**.
4. Встреча появится в списке предстоящих встреч владельца.
