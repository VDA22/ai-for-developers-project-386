# Навигация между страницами через реальные URL

В приложении есть главная страница и страница записи. Навигация построена на `react-router-dom` с путями `/` и `/booking`, а не на переключении состояния внутри `App`: страницу записи можно открыть или скопировать как отдельный адрес, и на следующем этапе бронирования не придётся переделывать переходы.
